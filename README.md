# Quickdraw-Detection---CS-5480-Final-Project
CS 5480 Final Project Repository containing source code for training YOLOv8 models to detect quickdraws. 

In each folder you have a .py and a best.pt file. The .py file is what we used to train the model and best.pt was the result of that script.
